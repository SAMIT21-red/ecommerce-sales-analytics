---

# 📌 Project Overview

This project analyzes an e-commerce company's sales, customer behavior, product performance, marketing effectiveness, and website conversion funnel.

Using Python for data analysis, Excel for interactive dashboards, and Power BI for business intelligence reporting, this project provides actionable insights to support business decision-making.

---

# 🎯 Business Objectives

This project answers key business questions such as:

- 📈 How are sales performing over time?
- 🛍 Which products generate the highest revenue?
- 👥 What percentage of customers return to purchase again?
- 📢 Which marketing channels drive the most revenue?
- 🌐 How effectively does the website convert visitors into customers?
- 🚪 At which stage do users leave the website funnel?

# 🚀 How to Run

## Python Analysis

Install the required libraries:

```bash
pip install -r requirements.txt
```

Run the notebooks in the following order:

1. `01_data_understanding.ipynb`
2. `02_eda.ipynb`
3. `03_visualization.ipynb`

---

## Excel Dashboard

Open:

```
dashboard/E-Commerce_Sales_Analytics_Excel.xlsx
```

Navigate through the dashboard pages using the Home page and interactive slicers.

---

## Power BI Dashboard

Open:

```
dashboard/E-Commerce_Sales_Analytics_PowerBI.pbix
```

Navigate across all dashboard pages and use slicers for interactive filtering.

# 📊 Key Metrics

| Metric | Definition |
|---------|------------|
| Gross Revenue | Total sales before refunds |
| Net Revenue | Gross Revenue − Refunds |
| Average Order Value (AOV) | Revenue ÷ Orders |
| Conversion Rate | Orders ÷ Sessions |
| Repeat Customer % | Repeat Customers ÷ Total Customers |
| Profit Margin | Profit ÷ Revenue |
| Refund Rate | Refunded Orders ÷ Total Orders |
| Funnel Drop-off % | Percentage of users leaving between funnel stages |

# ⚠ Limitations

- Dataset covers March 2012 – March 2015.
- No customer demographic information.
- No Customer Acquisition Cost (CAC) data.
- Marketing analysis is limited to the available website session data.
- Inventory and supply-chain analytics are outside the scope of this project.
